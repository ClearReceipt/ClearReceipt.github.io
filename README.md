# clearreceipt.github.io

Public website for the ClearReceipt iOS app, served by GitHub Pages at https://clearreceipt.github.io/

| Path | Purpose |
|---|---|
| `/` | Home page |
| `/privacy/` | Privacy policy (App Store Connect "Privacy Policy URL") |
| `/support/` | Support page (App Store Connect "Support URL") |
| `/app-ads.txt` | AdMob authorized-seller file; must stay at the domain root |

Plain HTML/CSS, no build step. Edit the files and push to `main` to publish.
